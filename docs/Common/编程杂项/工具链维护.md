# 工具链维护

## Arch Linux

全局更新
```bash
sudo pacman -Syyu
sudo yay -Syyu
rustup update
```

更新`nvm`
```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
```


更新`npm`
```cmd
npm install -g npm
```

安装最新版本`Node`及其对应的`npm`
```bash
nvm install --lts
nvm install-latest-npm
```

更新`pip`
```
python -m pip install --upgrade pip
```

查看`JDK`版本
```bash
archlinux-java status
```

## Windows

更新`Visual Studio` 现有模块
```cmd
"C:\Program Files (x86)\Microsoft Visual Studio\Installer\setup.exe" updateAll
```

更新`rust`
```cmd
rustup update
```

更新`pip`
```cmd
python -m pip install --upgrade pip
```

看看有没有新的`Python`要安装
```cmd
pyenv versions
pyenv install -l
```

更新由 `winget` 管理的软件

```cmd
winget upgrade --all
```

启动`Windows更新`并安装

```cmd
UsoClient ScanInstallWait
```

其它日常维护：

- Android Studio 及其相关 SDK
- 杀毒软件定期扫描（扫描前先更新病毒库）
- 定期查找最新专门工具，专杀银狐病毒

额外的常用扫描软件（不包含实时防护功能）

- ESET Online Sanner（手动安装）
- Microsoft Safety Scanner（winget安装）
- AdwCleaner（winget安装）

> 查看 winget 安装目录的方法：
>
> ```cmd
> winget --info
> ```
>
> 用户范围：
>
> - %LOCALAPPDATA%\Microsoft\WinGet\Packages
>
> 全局范围：
>
> - C:\Program Files\WinGet\Packages
> - C:\Program Files (x86)\WinGet\Packages
